用官方客户端连接

也可以直接用 Bitwarden 的浏览器扩展 / 手机 / 桌面客户端，把「服务器地址」填成：

https://vault.example.com

客户端下载： bitwarden.com/download · 网页版：/vault/

步骤

  1. 安装 Bitwarden 客户端（Chrome/Firefox 扩展、Android、iOS、桌面版均可）
  2. 登录页点「设置」→「自托管环境」，填入上面的服务器地址
  3. 注册账号（需在服务器白名单内），或直接用已有账号登录

服务状态

健康检查：/api/alive · 服务配置：/api/config

API 正常

数据存储于 EdgeOne 边缘对象存储，主密码与库内容端到端加密，服务端不可读。
